# 4-bit ALU using Logisim Evolution

## Project Description

This project implements a 4-bit Arithmetic Logic Unit (ALU) using Logisim Evolution.

## Operations

- Addition
- Subtraction
- AND
- OR

## Inputs

- A (4-bit)
- B (4-bit)
- S1
- S0

## Output

- Y (4-bit)

## Software Used

- Logisim Evolution
